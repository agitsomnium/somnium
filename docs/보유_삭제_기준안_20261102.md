# 보유·삭제 기준안 (자료 종류별) — 2026-11-02

법률 자문이 아니다. 아래 «근거»는 웹에서 확인한 **2차 자료**(해설·위키·보도)이며, 조문 원문(국가법령정보센터 law.go.kr)은 확인하지 못했다. 기관이 원문으로 확인한 뒤 확정한다. 시행령은 2026-09-10 일부개정 이력이 있어 특히 그렇다. 표의 «권고»는 이 문서 작성자의 제안이지 법정 기한이 아니다.

## 확인된 근거 (2차 자료)
| 내용 | 확인 수준 |
|---|---|
| 정보주체가 삭제를 요구하면 지체 없이 조사·조치하고 **요구받은 날부터 10일 이내**에 결과를 알린다. 다른 법령이 수집 대상으로 명시한 정보는 삭제 요구를 거절할 수 있다(이때도 10일 안에 이유·이의제기 방법 통지). 삭제는 복구·재생되지 않게 한다. | 개인정보 보호법 제36조, 시행령 제43조 — 2차 자료 다수, 원문 미확인 |
| 처리 목적이 달성되는 등 불필요해지면 지체 없이 파기(자료에 따라 «5일 이내»로 설명) | 법 제21조 계열 — 시행령 조문 번호·기한 원문 미확인 |
| 개인정보처리시스템 **접속기록은 1년 이상 보관**(5만 명 이상 또는 고유식별·민감정보 처리 시 2년), 월 1회 점검 | 안전성 확보조치 기준 제8조 — 2차 자료, 소규모 예외를 찾지 못함 |
| «1년 미이용 시 휴면 전환·파기» 제도는 2023-09 개정으로 삭제 | 2차 자료. 따라서 «1년»을 법정 기한으로 쓸 수 없다 |
| 처리방침에는 보유·이용 기간, 파기 절차·방법, 보호책임자 또는 고충 처리 부서·연락처를 적는다 | 법 제30조 — 원문 미확인 |
| 보호책임자 지정은 원칙적 의무이나 소상공인기본법상 소상공인은 면제 가능(시행령 제32조). 비영리 단체가 이에 해당하는지는 기관이 확인. 2026-02 국회 통과 개정안이 대표자 최종 책임을 명시 — 시행일·기준 미확인 | 2차 자료 |

## 자료 종류별 표
| 자료 | 위치 | 법적 근거로 확인된 것 | 권고안 | 기관이 정할 것 |
|---|---|---|---|---|
| 이메일·이름·전화·후원자명·동의 기록 | Supabase `auth.users`, `profiles` | 의무 보존 근거 확인된 것 없음. 삭제 요구 10일 | 탈퇴·삭제 요구 시 10일 이내 삭제(회신 포함). 후원 종료 뒤에는 강의 접근만 닫고 계정은 유지, **미접속 N개월 후 안내 메일 → 삭제** | N(제안 12개월은 법정 아님, 운영 편의) |
| 후원 확인 상태·확인자·시각 | `supporters` | 후원금·영수증 증빙은 한빛누리 몫(이 시스템에 금액·계좌 없음) | 계정 삭제 때 함께 삭제 | — |
| 수강 코드 이용권 | `series_entitlements` | 확인된 것 없음 | 계정과 함께 삭제. 이용권이 있는 동안은 계정 유지 | — |
| 수강 코드 시도 기록 | `code_attempts` | 없음. 보안(무차별 대입 방지) 목적 | 짧게(제안 30일) 보관 후 삭제 | 기간 |
| 운영 처리 기록 | `audit` | 접속기록 1년 이상(제8조, 2차). 이 표가 «접속기록»에 해당하는지는 기관 판단 | **최소 1년 보관**(식별 값은 삭제 시 `erased`로 치환, 행은 유지) | 해당 여부·기간 |
| 로그인 세션·토큰 | Supabase Auth | 없음 | 계정 삭제 시 함께 삭제. 현재 세션 9·토큰 13, 인증 로그 테이블 0건 | 세션 만료 설정 확인 |
| 인증 메일 사본 | 기관 Gmail 보낸편지함(발송 시 수신자 이메일이 남음). 시험 11통(수신자=기관) | 없음 | 보낸 인증 메일을 주기적으로 삭제(예: 월 1회 `in:sent subject:[솜니움]` 검색 후 삭제) | 주기·담당 |
| 암호화 백업 | 기관 Drive `강의실_백업` | 삭제 요구는 복구·재생 불가여야 함 | 월 1회·최근 3개만 보관(약 3개월 뒤 소멸). 복원할 때는 «삭제 장부(UUID와 삭제일, 이름·이메일 없음)»를 다시 적용 | 보관 개수 |
| 호스팅 접속·Access 로그 | Cloudflare | 기관 통제 밖 | 처리방침에 처리 위탁·국외 이전 해당 여부를 기관이 확인해 기재 | 문안 |
| 후원 내역·영수증 | 한빛누리(별도 처리자) | 별도 | 이 시스템에 두지 않음 | — |
| 생년월일(미수집) | `profiles.birth` | 수집 중단 | 현재 1건(시험 프로필). **가입 개방 전 비우기(승인 후 실행)**, 컬럼 제거는 별도 마이그레이션 | 승인 |

## 사람이 정해야 할 것(이 표에서)
1) 미접속 N개월, 2) 처리 기록 보관 기간·해당 여부, 3) 인증 메일 사본 정리 담당, 4) 처리방침 문안. 위 «권고»는 확정 전까지 시행하지 않았다. 어떤 실제 자료도 삭제하지 않았다.
