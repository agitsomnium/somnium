# 보유·삭제 기준안 (자료 종류별) — 2026-11-02

법률 자문이 아니다. 아래 «근거»는 2026-11-02에 **국가법령정보센터(law.go.kr) 조문 원문**으로 확인했다(개인정보 보호법 [시행 2026.9.11., 법률 제21445호], 시행령 [시행 2026.9.11., 대통령령 제36671호], 안전성 확보조치 기준 [시행 2026.7.1., 고시 제2026-9호]). 원문 확인은 문구 대조이지 법률 자문이 아니며, 적용 해석은 기관이 확정한다. 표의 «권고»는 이 문서 작성자의 제안이지 법정 기한이 아니다.

## 확인된 근거 (원문 확인, 2026-11-02)
| 내용 | 확인 수준 |
|---|---|
| 정보주체가 삭제를 요구하면 지체 없이 조사·조치하고 **요구받은 날부터 10일 이내**에 결과를 알린다. 다른 법령이 수집 대상으로 명시한 정보는 삭제 요구를 거절할 수 있다(이때도 10일 안에 이유·이의제기 방법 통지). 삭제는 복구·재생되지 않게 한다. | 법 제36조①②③·시행령 제43조③ — **원문 확인**(시행령 제43조③: 요구받은 날부터 10일 이내 조치·통지, 거절 시에도 10일 이내 사유·이의제기 방법 통지). 법 제36조③: 삭제는 «복구 또는 재생되지 아니하도록» |

| «1년 미이용 시 휴면 전환·파기» 제도는 2023-09 개정으로 삭제 | 법 제39조의6이 현재 «소송기록 열람 등의 청구 통지 등»으로 되어 있어 휴면 조항은 없음(원문 확인). 따라서 «1년»을 법정 기한으로 쓸 수 없다 |
| 처리방침에는 보유·이용 기간, 파기 절차·방법, 보호책임자 또는 고충 처리 부서·연락처를 적는다 | 법 제30조①2호·3의2호 — **원문 확인**(처리·보유 기간, 파기 절차·방법) |

## 자료 종류별 표
| 자료 | 위치 | 법적 근거로 확인된 것 | 권고안 | 기관이 정할 것 |
|---|---|---|---|---|
| 이메일·이름·전화·후원자명·동의 기록 | Supabase `auth.users`, `profiles` | 의무 보존 근거 확인된 것 없음. 삭제 요구 10일 | 탈퇴·삭제 요구 시 10일 이내 삭제(회신 포함). 후원 종료 뒤에는 강의 접근만 닫고 계정은 유지, **미접속 N개월 후 안내 메일 → 삭제** | N(제안 12개월은 법정 아님, 운영 편의) |
| 후원 확인 상태·확인자·시각 | `supporters` | 후원금·영수증 증빙은 한빛누리 몫(이 시스템에 금액·계좌 없음) | 계정 삭제 때 함께 삭제 | — |

## 사람이 정해야 할 것(이 표에서)
1) 미접속 N개월, 2) 처리 기록 보관 기간·해당 여부, 3) 인증 메일 사본 정리 담당, 4) 처리방침 문안. 위 «권고»는 확정 전까지 시행하지 않았다. 어떤 실제 자료도 삭제하지 않았다.
