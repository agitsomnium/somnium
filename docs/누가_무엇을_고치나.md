- 날짜는 `2026-11-12`처럼 적습니다. 날짜를 적으면 달력의 지난달·이번 달·다음 달 칸에 저절로 들어갑니다.
- 시트를 고치면 **다음 날 아침 6시**에 홈페이지가 바뀝니다. 급하면 GitHub Actions에서 「시트에서 홈페이지 만들기」를 수동 실행합니다.
- 칸 이름과 순서는 바꾸지 않습니다(`docs/시트_설계.md`).
- 유튜브 채널의 **최신 영상**은 시트에 적지 않아도 매일 자동으로 들어옵니다.

## 2. 운영진 — GitHub 웹에서 글 파일 고치기 (가끔)

GitHub 저장소 화면에서 파일을 열고 연필 아이콘으로 고친 뒤 저장(Commit)하면 몇 분 안에 반영됩니다.

| 고칠 것 | 파일 |
|---|---|
| 계좌·CMS 링크·이메일 | `config/site.json` 의 accounts, cms_url, email |
| 유튜브·인스타·페북 주소 | `config/site.json` 의 youtube, instagram, facebook |
| 이사진 이름 | `config/site.json` 의 board — 자리마다 「이름」 칸에 적기. 비우면 「명단 정리 중」으로 나옴 |
| 소개·연혁·오시는 길·후원 안내 글 | `content/*.md` |
| 인스타 최신 글 6개 | `config/site.json` 의 instagram.behold_feed_url (behold.so 무료 피드 주소) |
| 도메인·검색 등록 | `config/site.json` 의 site_url, verification(구글·네이버 확인 코드) |
| 검색·AI 소개 문장·검색어 | `config/site.json` 의 seo (description, keywords) |

- `config/site.json`은 따옴표·쉼표 하나만 빠져도 깨집니다. 저장 전에 다른 줄과 모양이 같은지 봅니다. 깨지면 Actions의 시험 단계에서 멈추고 홈페이지는 이전 판 그대로 남습니다.

## 검색·AI 홍보 장치 (자동)

- 쪽마다 설명·공유 미리보기(카톡·페북 링크 카드)·대표 주소가 자동으로 붙습니다.
- 날짜가 적힌 세미나 회차·북클럽은 구글·네이버·AI 검색이 읽는 「행사 정보」로 자동 표시됩니다.
- `robots.txt`는 ChatGPT·Claude·Perplexity·Gemini 수집기를 허용합니다. `llms.txt`는 AI가 솜니움을 한 번에 이해하도록 쓴 요약이며 시트에서 자동으로 만들어집니다.
- 도메인을 적으면 `sitemap.xml`이 생깁니다. 구글 서치 콘솔과 네이버 서치어드바이저에 사이트맵을 한 번 등록합니다.
