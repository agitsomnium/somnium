# 백업 복호화 비밀 — 기관 보관 절차

## 먼저: «2인 이상»은 필수인가
**법적으로 필수라는 근거를 찾지 못했다.** 확인한 안전성 확보조치(암호화·접근통제·접속기록)는 보관자 수를 정하지 않는다(고시 제8조·시행령 제30조 원문 확인, 2026-11-02). «2인 이상»은 한 사람이 없어도 복구되게 하려는 **운영 권고**다. 기관이 사람이 한 명뿐인 구조를 감수한다면 1인으로도 규정 위반은 아니라고 보지만, 그 경우 «기관 독립 복구»는 «그 한 사람 없이는 복구 불가»로 정직하게 적어야 한다. 이 문서는 2인을 **권고**로 둔다.

## 현재 상태
- 암호화 백업(AES-256, 일련번호 `20261102`)은 기관 Drive `강의실_백업`(소유 agit.somnium, 제한 공유)에 있고, 내려받아 지문이 일치했다.
- 복호화 비밀은 이 Mac 키체인 항목 `somnium-classroom-backup-20261102`에만 있다. **이 Mac이 없으면 백업은 열 수 없다.**

## 쓰는 기존 도구 (새 서비스·유료 없음)
1. 기관 Google 계정(agit.somnium)의 **Google 비밀번호 관리자** — 이미 사용 중, 2단계 인증·패스키 보호.
2. 기관 Drive 폴더 `강의실_백업`(암호화 파일만 둔다. 비밀은 두지 않는다).
3. 이 Mac 키체인(현 보관처) · 종이 인쇄(두 번째 보관).
4. 복호화·무결성 점검 스크립트 `supabase/ops/decrypt_integrity_check.py`(이번에 추가, 비밀은 숨김 입력, 아무것도 복원하지 않고 지문만 검증, 시험 통과).

## 절차 (사람이 하는 단계는 [사람])
**1. [사람] 비밀을 기관 계정 비밀번호 관리자에 넣기** — 화면·채팅에 값을 찍지 않는다.
터미널에서 아래를 실행하면 비밀이 클립보드에만 복사된다(출력 없음).
```bash
security find-generic-password -s somnium-classroom-backup-20261102 -w | tr -d '\n' | pbcopy
```
agit.somnium 계정의 passwords.google.com에서 «새 비밀번호 추가»: 사이트 `솜니움 강의실 백업`, 사용자 이름 `복호화 비밀`, 비밀번호에 붙여넣기 → 저장. 그 뒤 클립보드를 비운다.
```bash
pbcopy < /dev/null
```
> 주의: 클립보드는 같은 Apple ID의 다른 기기로 공유(유니버설 클립보드)되거나 클립보드 관리 앱에 남을 수 있다. 1번은 한 번에 끝내고 바로 비운다.

**2. [사람] 두 번째 보관(권고)** — 같은 비밀을 종이에 인쇄(또는 손으로 적어) **밀봉**해 책임자가 아닌 구성원 1인에게 맡긴다. 인쇄 후 클립보드·휴지통·프린터 대기열을 비운다. Google 백업 코드 10개(계정 복구용)도 같은 방식으로 분산한다(`계정_복구_현황_20261102.md`).
**3. [사람 또는 훈련 담당] 복호화·무결성 점검** — 비밀을 «꺼내는 쪽»(비밀번호 관리자 또는 봉인본)에서 직접 보며 다른 기기에서 실행한다.
```bash
python3 supabase/ops/decrypt_integrity_check.py /내려받은/somnium-classroom-backup-….tar.gz.enc
```
프롬프트에 비밀을 입력(화면에 안 보임). 기대 결과: `tables 16 rows 258 files 11 bytes 7367016` 과 `CHECK PASS`. 잘못된 비밀이면 `CHECK FAIL`.
**4. 완료 판정** — 3번을 **Mac 키체인을 쓰지 않고** 통과해야 «기관 독립 복구(복호화까지)»로 적는다. 아직 하지 않았다.
**5. 주기** — 새 백업을 만들 때마다 새 일련번호 비밀을 같은 방식으로 두 곳에 등록하고 직전 비밀은 직전 백업 삭제 때까지 둔다. 반기 1회 훈련.

## 이것으로도 안 되는 것
복호화·지문 검증은 «데이터가 온전하고 열린다»까지다. 실제 Supabase 인증 서버(비밀번호·세션·메일 설정)를 새로 세워 로그인까지 되살리는 독립 복원은 검증하지 않았다(`CODEX_REVIEW` 참고).
