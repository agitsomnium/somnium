자동 시험 3묶음이 통과했습니다. unittest 결과는 tests/test_operations.py로 재현할 수 있습니다.

| 실제 CLI 샘플 빌드 | 종료코드 0과 index.html 생성 |

## 화면 확인

A/B 첫 화면·세미나 상세의 PC 1440px와 모바일 375px, 총 8화면에서 HTTP 200, 가로 넘침 없음, 이미지 로드, h1 한 개를 확인했습니다. 질문의 details/summary는 브라우저 기본 키보드 조작을 사용합니다. 최종 browser-checks.json과 Lighthouse 결과를 함께 보관합니다.

미감 채택은 자동 점수와 구분합니다. 기존 시안은 사용자 요청으로 보류했고 재구성 시안의 최종 선택은 아직 받지 않았습니다.

## 아직 시험하지 않은 것

실제 Google Sheet는 사람이 만들 예정이어서 공개 CSV의 실제 다운로드, 조직 저장소 Actions의 원격 실행과 Pages 공개는 미실행입니다. 계정 복구·관리자 2명 인수인계·도메인/DNS/후원/구글폼 최종 확인도 사람 차례입니다. 실제 간사의 사용성 시험은 이 샘플 재현과 별도로 진행합니다.

강의 정리글은 일부공개 영상 URL을 기다려 생성·Batch 제출하지 않았습니다.

## 최종 자동 측정

Lighthouse 모바일 모의 환경: 접근성 100, 권장사항 100, SEO 100, 성능 78. LCP 4.2초로 느린 모바일의 추가 최적화 여지는 남아 있습니다. 로컬 서버 측정이며 실제 GitHub Pages의 속도나 이용자 성과를 입증하는 값은 아닙니다. 백업은 원문 10개·이미지 40개의 SHA256을 다시 대조해 50/50 일치를 확인했습니다. 정상 CSV 내려받기 시험도 보호된 임시 폴더에서 재현해 교체와 내용 일치를 확인했습니다.
