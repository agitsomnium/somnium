## 공개 주소에서 확인한 것 (실제 이메일 인증번호, 시험 회원 `agit.somnium+classroom1102@…`)
1. 가입(이메일 인증 → 이름·생년월일·휴대전화·동의 → 일반회원). **가입 제출은 같은 배포 파일을 로컬(127.0.0.1)에서 열어 했다**(공개 주소에서 새 계정을 직접 만들지 않음). 같은 Auth·DB에 기록됨.
2. 공개 주소에서 해당 회원 로그인 → 후원 확인 전: 강의 목록 숨김, «후원 확인 요청» 단추 → 요청(DB `pending`).
3. 공개 주소에서 관리자 로그인 → 회원·후원 확인 목록에서 후원 확인란 체크 후 «후원 자격 승인» → DB `qualified`.
4. 다시 회원 로그인 → «모든 회원 강의 이용 가능», 등록 영상 93개, 자료 PDF 버튼 5개, 강의 재생 틀 표시, PDF 실제 저장(%PDF, 3,200,100바이트, sha256이 자료 원본 manifest와 일치).
5. 1440/390 폭에서 안내·로그인 화면 가로 넘침 없음, 검토용 문구 없음. 캡처: `public-20261102/shots/`.

## 남은 일·주의
- **회원 삭제 함수 미적용.** 삭제 요청을 받아도 후원 확인 기록이 있는 회원은 현재 DB에서 지워지지 않는다(처리방침은 10일 이내 삭제를 약속함). 삭제 마이그레이션과 장부 적용 승인이 필요하다.
- 시험 회원 `classroom1102`가 운영 DB에 `qualified`로 남아 있다. 지표에서 제외하거나 종료 처리 필요(삭제는 위 마이그레이션 뒤).
- DB의 동의 버전 값이 `somnium-v1-draft` 그대로다(새 문안과 이름 불일치, DB 변경 필요).
- 호스팅은 `noindex`(검색 노출 안 함) 상태다. 홈페이지 `참여·후원`에 링크는 넣지 않았다.
- Supabase 기본 이메일 발송 한도·봇 방지는 확인하지 못했다(가입이 몰리면 인증 메일이 늦을 수 있음).
- 개인정보 보호책임자 실명·연락처는 문의 메일로만 표기했다. Cloudflare 2단계 인증, 백업 비밀 기관 보관은 여전히 미완료.
