# 시즌1 강의 정리글 준비 상태

2026-10-18. 원천 영상 URL을 기다립니다. 강의 정리글과 강사 소개의 내용 생성·유료 API 제출은 아직 하지 않았습니다. 현재까지 이 강의 작업에 사용한 Anthropic 프로모 크레딧은 $0입니다(외부 청구 잔액을 확인했다는 뜻은 아닙니다).

기존 우피 10개 페이지의 공개 HTML·페이지 데이터와 공개 웹 검색에서 시즌1 회차별 URL을 찾지 못했습니다. 두 유튜브 채널 주소만 확인됐습니다. 일부공개 영상은 채널 목록에 나오지 않을 수 있어 사용자에게 링크 목록을 요청했습니다. 홈페이지 구축은 계속합니다.

사용자에게 확인된 조건: 2026-10-19 18:00 KST 전에 본 제출, 전체 상한 $30, 크레딧 만료 2026-10-21 09:00 KST. 만료·잔액은 사용자 제공 정보이며 결제 콘솔 실측은 아직 하지 않았습니다.

## 링크를 받으면 진행할 순서

1. 각 URL에서 yt-dlp로 ko 자동자막을 받아 docs/transcripts/에 원문·영상 ID·수집시각과 함께 저장합니다. 자막이 없는 회차를 표시하고 강의 내용을 만들어 채우지 않습니다.
2. Python으로 VTT 중복 자막·시간표시를 정리하고 발화 순서대로 나눕니다. 원문과 대응되는 시간 범위를 유지합니다. 강사 신상은 자막만으로 추측하지 않습니다.
3. 문체_문어_v1 v1.3을 참조해 경어체 정리글을 요청합니다. 원문 밖 사실과 참고문헌은 추가하지 않으며, 원본 링크·시간대·「강사 확인 전」을 각 초안에 붙입니다.
4. 모델 ID claude-opus-5-5, Batch API를 사용합니다. 공식 문서에서 모델 제공과 배치 50% 할인(입력 $2 / 출력 $10 per 1M tokens)을 확인했습니다. 생각 토큰도 출력 한도와 비용에 포함해 상한을 계산합니다. 두 시험과 본 제출의 합계로 $30을 제한하고, 최대 출력 토큰까지 잡아 제출 전 예산을 통과시킵니다.
5. 시험 2건을 먼저 제출·회수해 원문 대조와 문체·표시·누락을 검토합니다. 통과 뒤에만 나머지를 본 제출합니다. 중복 제출을 막기 위해 요청 해시와 batch ID를 보호된 로컬 기록에 저장합니다. 모델 호출·비용은 model-router 장부에 기록합니다.
6. docs/lecture-drafts/에 초안을 저장합니다. 자동으로 dist/나 공개 시트에 옮기지 않습니다. 일부공개 URL도 공개 여부를 별도 확인합니다.
