# 시트 설계

2026-10-18 · 실제 시트는 사람이 만듭니다. 공개 CSV는 인증 없이 누구나 읽을 수 있습니다.

## 세미나

id, 제목, 부제, 소개, 상태, 시작일, 종료일, 장소, 강사진_id, 신청_url, 취소사유, 공개, 정렬

## 회차

id, 세미나_id, 회차, 제목, 날짜, 시간, 자료_url, 공개

## 북클럽

id, 제목, 도서, 소개, 날짜, 시간, 장소, 신청_url, 상태, 취소사유, 공개, 정렬

## 강사진

id, 이름, 소개, 사진_url, 공개, 정렬

## 영상

id, 제목, youtube_url, 세미나_id, 회차_id, 날짜, 공개, 정렬

## 공지

id, 제목, 본문, 링크_url, 게시일, 공개, 정렬

ID는 영어 소문자·숫자·하이픈, 날짜 YYYY-MM-DD, 시간 HH:MM(한국 시각), 공개 예/아니오, 정렬은 0 이상 정수입니다. 상태는 예고/모집중/진행중/종료/취소. 취소사유는 취소 때 필수입니다. 비공개 자료와 신청자 정보는 시트에 넣지 않습니다.

강사진_id는 세미콜론으로 연결합니다. 회차는 세미나_id, 영상은 세미나_id와 회차_id를 연결합니다. ID를 바꾸면 기존 주소가 바뀝니다. 칸 이름과 순서를 유지합니다. 공개한 자료가 숨긴 자료를 참조하면 빌드가 멈춥니다.

샘플 CSV의 날짜·신청 주소는 확인되지 않아 비워 두었습니다. 샘플은 운영 데이터로 자동 대체되지 않습니다.
