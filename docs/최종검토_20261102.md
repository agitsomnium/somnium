2. **강사 공개 허락**: 공개 안내에 이름이 나가려면 각 강사의 허락이 필요하다. 현재 공개 확인은 정용택 선생님뿐. 확인할 시리즈·강사 — 2024 정치신학 세미나(최순양·정태창·박성철·홍철기·고지현·홍용진) · 현대 정치철학의 스펙트럼(허경·민승기·김재인·주형일·진태원·이택광·하상복·조현준 외) · 신학과 정치사회이론 세미나(박상훈·서복경·이상길·김항·한상원 외) · 동아시아 근대성과 기독교(옥성득·김건우·오동일·홍이표). 허락 전에는 공개 안내에서 이름이 자동으로 빠진다.
3. **추천 입문 순서 승인**(`order.approved`)과 맛보기 영상 여부.
4. **동의 문안·처리방침 확정**(보유·삭제 기간 숫자 포함 — `보유_삭제_기준안`의 «기관이 정할 것»).
5. **계정 보안 설정**: Cloudflare 2단계 인증, Google 백업 코드(`계정_복구_현황`).
6. **백업 복호화 비밀을 기관 쪽에 등록**하는 손 작업(`백업_비밀_보관_절차`).
