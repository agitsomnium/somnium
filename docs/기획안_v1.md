# 솜니움 홈페이지 기획안 v1

2026-10-18 · 검토용 · owner: Codex · 공개 배포 전

수정: 같은 날 사용자 요청으로 색·폰트·레이아웃 전면 재구성. 현재 디자인은 디자인시스템_적용.md를 따릅니다.

## 누구에게 어떤 곳으로 보일까요?

연구자와 시민이 만나는 광장을 만듭니다. 첫 화면에서는 솜니움이 함께 붙드는 질문과 연구 방법을 먼저 보여 주고, 그 질문을 세미나·북클럽·기록으로 이어 줍니다. 대표가 2년 뒤 바뀌어도 조직 계정과 문서만으로 운영을 이어 갈 수 있어야 합니다. 간사는 주 1일의 업무 안에서 구글시트만 고칩니다.

## 첫 화면은 무엇을 보여 줄까요?

질문 문안은 검토용 초안입니다. 기존 미션·비전은 백업 원문과 대조해 보존합니다.

- 오늘의 자본주의는 우리의 일과 삶을 어떻게 바꾸고 있을까요?
- 기독교는 정치사회 현실에서 어떤 시민의 삶을 만들 수 있을까요?
- 이론이 놓치는 주변부의 경험은 무엇을 말해 줄까요?
- 함께 읽고 토론하는 일은 어떤 사회적 변화를 만들 수 있을까요?

연구 방법: 정치사회이론을 함께 읽고, 연구자의 설명과 시민의 경험을 나누며, 토론에서 나온 질문을 다음 공부와 기록으로 이어 갑니다. 그 아래에 진행 중인 세미나, 북클럽, 지난 기록, 참여 안내를 배치합니다.

## 첫 공개에 어떤 프로그램을 담을까요?

- 세미나 시즌1 「현대 자본주의 이해하기」: 6회, 이끔이 정용택. 실제 날짜·회차 제목·신청 URL은 기존 사이트와 대조합니다.
- 예고: 2부 메자드라·닐슨 『작동의 정치』, 3부 아르볼레다 『행성적 광산』. 예고 단계임을 표시합니다.
- 지난 기록: 버틀러 세미나, 2025 정치×문화×종교.
- 북클럽: 10월 『손절사회』, 11월 『가까스로-있음』.
- 강사진 표기는 모든 화면과 자료에서 통일합니다.

## 시트는 어떤 칸으로 만들까요?

모든 탭은 첫 줄이 칸 이름입니다. ID는 한 번 정하면 바꾸지 않습니다. 날짜는 YYYY-MM-DD, 시각은 HH:MM(한국 시각), 공개는 예/아니오로 통일합니다. 아래 설계를 샘플 CSV와 검증기의 정본으로 씁니다.

| 탭 | 칸 이름 |
|---|---|
| 세미나 | id, 제목, 부제, 소개, 상태, 시작일, 종료일, 장소, 강사진_id, 신청_url, 취소사유, 공개, 정렬 |
| 회차 | id, 세미나_id, 회차, 제목, 날짜, 시간, 자료_url, 공개 |
| 북클럽 | id, 제목, 도서, 소개, 날짜, 시간, 장소, 신청_url, 상태, 취소사유, 공개, 정렬 |
| 강사진 | id, 이름, 소개, 사진_url, 공개, 정렬 |
| 영상 | id, 제목, youtube_url, 세미나_id, 회차_id, 날짜, 공개, 정렬 |
| 공지 | id, 제목, 본문, 링크_url, 게시일, 공개, 정렬 |

상태 값: 예고 / 모집중 / 진행중 / 종료 / 취소. 강사진이 여럿이면 강사진_id에 세미콜론으로 연결합니다. 회차와 영상은 존재하는 세미나·회차 ID를 참조합니다. 필수 칸·날짜·중복 ID·참조·안전한 URL 검증이 실패하면 전체 빌드를 멈춰 기존 공개 사이트를 보존합니다.

## 어떻게 자동으로 갱신하나요?

구글시트의 공개 CSV → GitHub Actions(매일 1회, 수동 실행) → Python 검증·정적 HTML 생성 → 승인 후 GitHub Pages. 고정 글은 Markdown입니다. 시트 주소는 저장소 설정 파일 한 곳에 두며, 미설정 상태에서는 샘플을 자동으로 공개하지 않습니다. 로컬에서만 --sample로 샘플을 씁니다. 일일 작업은 한국 시각 오전 6시(UTC 21시)를 목표로 하며 Actions 사정으로 지연될 수 있습니다.

Python 표준 라이브러리 중심으로 운영 의존성을 줄입니다. 외부 계정 로그인이나 DB 없이 완성 HTML을 읽습니다. 공개 활성화 전에는 배포 작업을 잠가 둡니다. 본 사이트에 Cloudflare·개인 Supabase는 연결하지 않습니다. Hub는 이 준비 작업의 기록에만 사용합니다.

## 두 시안은 무엇이 다를까요?

현재 A안은 차콜 바탕·푸른 강조·굵은 산세리프 제목의 질문 중심 연구소입니다. B안은 종이색 바탕의 밝은 편집형입니다. 사용자 피드백으로 기존 세리프 저널 시안은 보류했습니다. 현재 제목은 Pretendard 800, 본문은 400이며, 연구 질문과 연구 방법을 행사보다 먼저 보여 줍니다. 기존 솜니움 북클럽 포스터를 실제 이미지로 연결합니다. 본문 최소 16px와 넉넉한 행간을 사용합니다. 모바일 375px·키보드 이동·링크 대비·가로 넘침을 확인합니다.

2026-10-18 사용자 선택으로 A안 구조와 B안의 밝은 색을 밝기 선택으로 통합했습니다. 홈과 네 하위 페이지·세미나 상세에 공통 적용했습니다. 공개 배포는 사람 확인 뒤 진행합니다.

## 어떤 순서로 확인하나요?

1. 기획안과 휴대폰용 PDF 확인.
2. 우피 전체 내부 링크를 따라 원문 HTML·글·이미지와 주소·해시 목록 보존. 실패 주소는 별도 기록.
3. 여섯 탭 설계와 간사·관리자 인수인계 문서 작성. 실제 시트 생성은 사람 차례.
4. 첫 화면과 세미나 상세 각 2안, PC·모바일 화면을 드라이브 테스트/솜니움홈피에 공유.
5. 샘플 CSV로 빌드와 매일·수동 실행 워크플로 준비.
6. 등록·수정·취소, 종료 기록 유지, 잘못된 입력 차단 시험.
7. 도메인 후보 3개와 신규·갱신 연간 가격 조사. 결제는 사람 차례.

## 강의 정리글은 언제 만드나요?

시즌1 일부공개 영상 URL을 찾으면 ko 자동자막을 docs/transcripts/에 저장합니다. Python으로 중복·시간표시·분할을 처리하고 글 생성만 요청한 Opus 5.5 Batch API로 맡깁니다. 실제 모델 제공 여부와 배치 가격을 확인한 뒤 시험 2건을 검토하고 본 제출합니다. 다른 모델로 임의 대체하지 않습니다. 원본 URL과 「강사 확인 전」 표시를 각 초안에 넣고 공개 빌드에서는 제외합니다.

상한 $30, 제출 마감 2026-10-19 18:00 KST, 사용자 제공 크레딧 만료 2026-10-21 09:00 KST. 키체인 자격 정보는 출력·저장하지 않습니다. 링크를 찾지 못하면 이 단계만 멈추고 목록을 요청합니다.

## 사람 차례는 무엇인가요?
