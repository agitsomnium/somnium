# 하위 페이지와 밝기 선택 완성

2026-10-18 · 로컬 검토본 · 공개 배포 전

사람 선택 원문: “A안+B안(밝기 선택)으로 가자. 연구소 소개·프로그램·연구자료·참여·후원 페이지도 같은 디자인으로 완성해줘.”

## 현재 구성

| 페이지 | 구성 |
|---|---|
| 홈 | A안의 연구 질문·방법·세미나·북클럽 구조 |
| 연구소 소개 | 솜니움의 정신·미션·비전·슬로건·문제의식·방향, 이사회, 연혁, 주소·건물 사진·지도 |
| 프로그램 | 진행 중/예고 세미나, 펼쳐보는 지난 세미나, 북클럽 포스터·참여, 기획강좌·특강, 아지트솜니움 |
| 연구자료 | 실제 두 유튜브 채널, 시트 영상 목록, 세미나별 자료 경로, 강의 정리글 공개 절차 안내 |
| 참여·후원 | 참여 가능한 프로그램, 한빛누리 정기후원, 공개 원문의 일시후원 안내, 문의 |
| 세미나 상세 | 기존 회차·강사진·자료·신청·취소/종료 기록 유지 |

네 메뉴와 하위 목차, 제목·본문 위계·현재 메뉴 표시를 통일했습니다. 원문에 없는 강사 약력·영상·일정·신청 주소를 새로 만들지 않았습니다.

## 밝기

머리말의 어둡게/밝게 두 버튼이 전체 사이트에 적용됩니다. A안의 레이아웃은 공통이고 B안의 밝은 색을 선택합니다. 초기값은 어두운 화면이며 마지막 선택을 우선합니다. 이전 비교 주소 /b/도 같은 구조를 사용합니다. 브라우저 저장이 막히면 저장만 생략하고 현재 선택은 작동합니다. JavaScript 없이도 정적 본문과 링크를 읽을 수 있습니다.

## 실제 확인

- 자동 운영 시험 4묶음 통과. 공개 영상과 프로그램이 연구자료·참여 페이지에 실제로 나타나는 조건도 확인.
- 홈·네 하위 페이지·세미나 상세 × 두 밝기 × PC/모바일 = 24화면 HTTP 200, 이미지 로드, 가로 넘침 없음, H1 한 개.
- 밝기 선택 후 메뉴 이동·새로고침 유지, 다른 탭 동기화, 잘못된 저장값 복구, 저장 차단 환경 작동.
- 키보드로 질문 펼치기와 밝기 버튼 조작.
- 고정 글과 후원 원문 출처 보존. 건물 사진은 우피 백업에서 가져온 웹용 파생본.

실제 시트·새 도메인·GitHub Pages 공개는 이전 요청대로 사람 차례입니다. 날짜·강사진의 상세 약력·일부공개 영상·프로그램별 신청 링크의 추가 확인도 유지합니다. 홈페이지 화면 완성과 운영 자료의 최종 확정을 구분합니다.

추가 접근성 자동 검사: 프로그램 어두운 화면 100점, 연구자료 밝은 화면 100점. 이는 표본 화면의 기술 검사 결과이며 미감이나 전체 이용자의 사용성을 점수로 확정한 것은 아닙니다.
