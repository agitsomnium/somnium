# 솜니움 홈페이지

공개 전 로컬 준비본입니다. 조직 소유 GitHub Pages와 구글시트 공개 CSV로 운영합니다.

- 기획: `docs/기획안_v1.md`와 PDF
- 운영: `docs/인수인계.md`
- 시트: `docs/시트_설계.md`
- 로컬 샘플 빌드: `python3 scripts/build.py --sample`
- 운영 시험: `python3 -m unittest discover -s tests -v`

백업·자막·검수 전 강의 초안은 Git 추적과 공개 빌드에서 제외합니다. 저장소 생성·push·계정 작업·배포는 아직 하지 않았습니다.
