# 솜니움 회원 강의실 — 2026-11-01 검토본

현재 우선 범위는 **후원회원과 이사의 비공개 강의 이용**이다. 운영 홈페이지는 유지하며 이 코드는 집 맥북의 가상 데이터용 로컬 시험본이다. 기관 Supabase·클라우드 서버·실제 본인 확인 메일은 아직 연결하지 않았다.

## 최신 결정과 권한

| 대상 | 가입·확인 | 강의·자료 | 운영관리 | 회계 |
|---|---|---|---|---|
| 후원회원 | 신청·이메일 확인·관리자 월 1만 원 이상 후원 대조 | 모든 회원 강의 | 불가 | 미게시 |
| 이사 | 신청·이메일 확인·관리자 이사 명단 대조 | 후원 금액과 관계없이 모든 회원 강의 | 불가 | 공개 범위 미정, 현재 불가 |
| 운영관리자 | 단체가 지정한 개별 계정 (현재 가상 계정) | 모든 표시 강의 | 회원·자격·강의 관리 | 준비 화면만 |

후원과 이사 자격은 독립적이다. 한 자격이 종료돼도 다른 자격이 유효하면 강의를 이용한다. 계정 이용 중지는 두 자격과 관계없이 모든 영상·자료 접근을 차단한다. 가입 신청에 ‘이사’를 선택하거나 계정을 승인·재개하는 것만으로 자격을 부여하지 않는다. 명단 대조 후 관리자가 명시적으로 승인한다.

기존 이사 제외 결정은 11/1 사용자 지시로 변경됐다. 아지트솜니움 별도 역할은 추가하지 않았다. 간사 업무는 운영관리자에 포함한다. 이전 강의·현대자본주의·2027 신규 강의 모두 후원회원·승인된 이사에게 포함된다.

단강좌 구매는 우선 보류하고 구매 기능 전체를 현재 화면/API에서 비활성화했다. 주문·시리즈·수강권 명세와 시험 코드는 보존한다. 과거의 가상 구매 내역을 삭제하지 않으며, 현재 기본 실행에서 구매 자격만으로 강의를 열지 않는다. 실제 기존 유료 수강생 정보는 이 시험에 가져온 적이 없다. 향후 실제 구매 서비스는 별도 승인·정책·검증 후 연결한다.

## 열기와 검토

저장소 루트에서 실행한다.

```sh
python3 classroom/seed_demo.py --state ../supporters-private-20261101 --video ../trial-video.mp4
python3 classroom/server.py --state ../supporters-private-20261101 --port 8765
```

주소: http://127.0.0.1:8765/ — 집 맥북 전용. 에어는 집 맥북 원격접속 화면에서 확인한다. 서버는 127.0.0.1에만 바인딩하고 정확한 Host/Origin을 확인한다. 이 서버와 시험 메일함을 인터넷에 공개하지 않는다.

- ‘후원회원 / 이사 / 운영관리자’는 가상 이메일을 채운다. 인증번호 받기 → 시험 메일 확인 → 6자리 번호 입력으로 로그인한다. 실제 메일 본인 확인 서비스가 아니다.
- 후원회원과 이사: 시험 강의 8개가 보인다. 이사 계정에는 운영관리·구매 메뉴가 없다.
- 운영관리자 → 회원·후원: 후원 월 1만 원 확인, 이사 명단 확인, 자격 승인·종료, 계정 중지·재개를 각각 시험한다. 자격 회수·계정 중지·강의 숨김은 대상 확인창을 거친다.
- 운영관리자 → 강의·자료: 가상 MP4·자료 등록, 제목·소개·순서 수정, 표시/숨김, 이름으로 시리즈 선택을 검토한다. 8개 영상은 모두 6초 시험 영상이며 실제 Drive 강의는 넣지 않았다.
- 운영관리자 → 회계 보고 준비: ‘미게시·공개 범위 미정’과 이사진 전용/전체 공개 두 안만 확인한다. 실제 원장·보고서·개인정보·회계 숫자를 가져오지 않았다. 보고서 등록·공개 설정 API도 제공하지 않는다.

실제 개인 정보를 넣지 않는다. 입력은 @example.test 가상 주소만 허용한다. 이전 시험 폴더 trial-private, draft-private-20261030, review-private-20261031는 보존했다. 최신 상태는 supporters-private-20261101이다.

## 검증과 복구

```sh
python3 -m unittest discover -s classroom -p 'test_*.py' -v
python3 -m unittest discover -s tests -v
python3 scripts/build.py --sample
python3 classroom/backup_trial.py ../supporters-private-20261101 ../새백업폴더
python3 classroom/backup_trial.py ../새백업폴더 ../새복원폴더
```

복원은 원래 서버를 중지한 뒤 새 복원폴더를 `--state`에 지정한다. 기존 폴더를 덮어쓰지 않는다. DB/영상/자료와 후원·이사·주문 상태를 보존하며 세션·인증번호는 제거한다. 손상·누락·목록 누락·심볼릭 링크 자료는 복원·서버 시작을 거절한다. 복원 뒤 정상 변경한 상태도 다시 백업할 수 있다. 해시는 손상 검사이며 서명된 외부 백업을 대신하지 않는다.

권한·인증·미게시 회계·구매 차단·복원 시험은 31개다. 여기에는 미래 구매 기능을 명시적으로 켠 격리 회귀 시험도 포함한다. 일반 실행의 구매 기능은 항상 꺼져 있다. 과거 구매 회귀를 확인할 개발자만 `--enable-purchase-trial`을 사용할 수 있으며 현재 검토나 자동 알림은 이 옵션을 사용하지 않는다. 이 옵션만으로 실제 판매 서비스가 준비되는 것은 아니다.

최신 증거는 상위 supporters-first-20261101/에 보존한다. 10/31 Claude API 리뷰의 재시작 자동 후원 승인 결함, 입력 타입, 시리즈 순서 수정은 유지한다. 기존 코드·검토·코드 bundle은 review-20261031/ 및 completion-20261030/에 보존했다.

## 운영 연결에 남은 일

단체 소유 전용 Supabase·기관 개별 관리자/인계, 클라우드 인증·RLS·비공개 미디어와 호스팅, 실제 SMTP, 기관 백업·독립 복원, 아이폰 Safari 실기기 검증이 필요하다. 개인정보 보유/삭제 기간·문의 담당, 후원 재확인·종료 기준, 강사 허락은 확정해야 한다. 회계는 사람이 이사진 전용/전체 공개를 결정한 뒤 공개용 보고서와 열람 정책을 연결한다.

실제 영상은 요청마다 권한을 검사하는 클라우드 전달 구조가 필요하다. 이미 다운로드·버퍼링된 바이트는 회수할 수 없다. 현재 HTTP 쿠키·시험 메일함·간이 MP4 검사는 운영용 인증/미디어 구현으로 교체한다. 기존 공개 Pages·일정·영상 수집기에는 회원 정보·비공개 자료를 섞지 않는다.

11월 1일 21시(한국) 단발 검토 안내 automation-8은 최신 후원회원·이사·회계 미게시 기준으로 갱신했다. 운영 게시·도메인 전환·실제 메일·결제·신규 계정/프로젝트·유료 서비스는 진행하지 않았다.
