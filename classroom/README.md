# 솜니움 회원 강의실 — 로컬 격리 시험

이 폴더는 운영 홈페이지의 별도 브랜치에 추가한 시험 서버다. 공개 홈페이지 빌드, 관리 시트, 영상 수집기는 수정하지 않는다. 실제 개인정보·영상·한빛누리 거래 내역을 입력하지 않는다.

## 실행

```sh
python3 classroom/server.py --state ../trial-private --port 8765
# http://127.0.0.1:8765 (이 맥에서만 접근 가능)
python3 -m unittest discover -s classroom -p 'test_*.py' -v
```

Python 표준 라이브러리만 사용한다. 파일 업로드는 시험 MP4 10MB 이하, 자료는 텍스트만 지원한다. 가상 주소는 `@example.test`만 허용한다. 회원은 직접 신청하고 이메일 인증 후 관리자 승인을 기다린다. 관리자는 `admin.one@example.test`, `admin.two@example.test`로 각각 로그인한다. 실제 발송 대신 화면의 시험 메일함에서 이번 인증번호를 확인한다.

이 시험 메일함은 본인 확인 서비스가 아니다. 서버는 127.0.0.1에만 바인딩하고 Host·Origin을 제한한다. **이 서버·메일함·가상 관리자 초기화 코드를 클라우드에 배포하지 않는다.** 실제 운영은 전용 Supabase Auth·DB, 별도 클라우드 서버, SMTP로 교체하고 별도 검증해야 한다.

## 확인할 흐름

1. 가상 회원 신청 → 이메일 확인 → 승인 전 로그인·영상·자료 차단.
2. 관리자 이메일 인증 → 신청 내역 확인 → 한빛누리 수동 대조 체크 → 승인/보류.
3. 승인 회원 로그인 → 후원회원용 시험 영상 재생·자료 다운로드.
4. 관리자 이용 중지 → 기존 로그인 세션 폐기 → 다음 영상 바이트/Range·자료 요청 거부.
5. 아지트솜니움 회원용·기존 유료 수강생용 강의를 등록해도 후원회원 권한으로 열 수 없음. 유료 수강생 권한 부여는 이 시험 UI에서 제공하지 않음.
6. 각 관리자별 처리 시각·대상·동작 기록. 후원금액·CMS 거래 목록 저장 없음.

인증번호 5분 만료·일회성·5회 실패 제한·재요청 시 이전 번호 무효화. 세션 1시간·HttpOnly·SameSite=Strict, 상태 변경은 CSRF 확인. 로컬 HTTP 시험 쿠키이며 운영 HTTPS의 Secure 쿠키는 별도 구현 대상이다. 이용 중지는 서버로 오는 다음 요청부터 적용된다. 이미 다운로드/버퍼링된 내용을 회수하지는 못한다. 운영 영상은 짧은 세그먼트마다 현재 권한을 검사하도록 설계한다.

DB·영상은 `--state` 디렉터리(공개 repo/dist 밖)에 저장한다. 정적 파일은 명시한 HTML·JS·CSS·폰트만 제공한다. 회원·자료는 API에서 현재 권한을 확인하며 검색 방지 헤더와 no-store를 설정한다. noindex는 인증을 대신하지 않는다. 이번 시험은 공개 영상 자동수집에 회원 서버 연결을 전혀 추가하지 않는다.

## 아직 완료하지 않은 것

전용 Supabase 조직·프로젝트, 실제 이메일 본인 확인, 인터넷 테스트 URL·접근 제한, 아이폰 실기기, 운영 백업 예약·클라우드 복원, 관리자 초대/회수·MFA, 장시간 강의 스트리밍·변환·대용량 업로드, 정책 확정·개인정보 보유 기간·회원 탈퇴, 강사 공개 범위 허락. 현재 코드는 실제 회원 서비스를 운영할 수 있다는 증거가 아니다.
