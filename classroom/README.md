최신 사용자 방향을 반영한 **집 맥북 로컬·가상 데이터 전용** 초안이다. 실제 회원 서비스·구글폼·계좌조회·SMTP·PG·전용 Supabase는 연결하지 않았다. 공개 홈페이지·main·Pages·DNS·공개 영상 수집기는 수정하지 않았다.

홈페이지의 ‘후원회원 / 강좌 구매자 / 운영관리자’ 버튼은 시험 이메일만 채운다. 인증번호 받기 → 시험 메일 확인 → 화면에 표시된 번호 입력 순서로 로그인한다. 만료·오입력 시 인증번호를 다시 받을 수 있고, 화면을 닫았던 미확인 신청은 로그인 이메일을 넣고 ‘신청 이메일 확인 이어가기’를 누른다. 실제 이메일 본인 확인 서비스가 아니므로 이 서버와 시험 메일함을 인터넷에 배포하지 않는다.

## 5분 검토 순서

1. 후원회원 로그인: 이전 강의와 현대 자본주의·2027 신규 강의가 모두 추가 구매 없이 열린다.
2. 강좌 구매자 로그인: 강의 목록에서 단강좌 또는 시리즈 전체를 시험 신청한다. 신청만으로 영상·자료가 열리지 않는다. 실제 입금하지 않는다.
3. 운영관리자 로그인 → ‘구매 신청·입금’: 신청을 확인하고 시험 입금 확인 체크 후 수강권을 준다. 확인 누락은 거절된다. 같은 신청을 반복 확인해도 안내는 한 번 생성된다.
4. 구매자 재로그인 → 나의 강의실: 단강좌는 해당 강좌만, 시리즈는 해당 묶음의 강의가 열린다. 영상 재생·자료 다운로드·발송하지 않은 안내 내용을 확인한다.
5. 운영관리자 → 회원·후원: 월 1만 원 이상 후원 여부 확인 후 후원 자격 승인. 후원 자격 종료는 구매 수강권을 없애지 않는다. ‘계정 이용 중지’는 모든 접근을 차단하며 기존 세션도 폐기한다. 재개 시 다시 로그인해야 한다.
6. 운영관리자 → 강의·자료 등록: 이전/현대 자본주의부터/2027 구분과 시리즈를 지정하고 시험 MP4·텍스트 자료를 등록한다. 기본 숨김으로 등록하고, 등록 강의 관리에서 회원 목록 표시/숨김을 바꾼다. 숨김은 기존 수강권에도 적용된다. 이사·아지트솜니움 별도 역할은 없다.

간사 업무는 운영관리자에 통합했다. 후원 자격과 단강좌/시리즈 수강권은 분리되어 중복 보유할 수 있다. 이전 강의는 구매 신청을 거부한다. 2026-10-30 사용자 결정에 따라 월 1만 원 이상 후원회원에게 현대 자본주의와 2027 신규 강의도 포함한다. 비후원 구매자의 가격·시청기간은 미정이다. 검토본은 신청 당시 포함 강의를 고정해 나중 등록 강의가 기존 구매에 자동으로 열리지 않게 했다. 이 동작은 제안된 시험안이며 실제 판매 전 회차 범위·기간을 확정해야 한다.

## 시험과 한계

```sh
python3 -m unittest discover -s classroom -p 'test_*.py' -v
python3 -m unittest discover -s tests -v
python3 scripts/build.py --sample
```

시험은 실제 HTTP 요청으로 권한·영상/자료 바이트·Range·수강권 부여/회수·중복/타인 주문을 검증한다. 브라우저 화면 검증과 아이폰 실기기 검증은 구분한다. 클라우드 백업·실제 메일·Google Forms 연동·PG 계약/결제는 미완료다. 신청+계좌이체의 현재 화면은 본문 흐름을 대체한 가상 신청이며 실제 구글폼이 아니다.

PG는 나중에 주문의 검증된 결제완료를 수강권 부여에 연결할 수 있는 구조만 마련했다. 실결제 adapter·서명/웹훅 검증·정산·실제 환불·부분환불은 구현하지 않았다. 현재 취소 버튼은 가상 수강권만 회수하며 돈을 움직이지 않는다.

세션은 1시간 HttpOnly/SameSite=Strict, 변경은 CSRF 검사. 로컬 HTTP 쿠키이며 운영 HTTPS Secure 쿠키는 별도 구현 대상이다. 서버는 매 영상/자료 요청에 현재 권한을 확인한다. 이미 다운로드·버퍼링된 내용을 회수할 수는 없다. 운영 영상은 짧은 세그먼트마다 권한을 확인하는 클라우드 구조가 필요하다.

백업: `python3 classroom/backup_trial.py ../review-private-20261031 ../새백업폴더`. 세션/인증번호 제외. 같은 도구로 백업을 새 복원폴더로 복사하고 검사한다. 운영 클라우드 백업을 대신하지 않는다. 운영 복원 자료와 기존 맥락은 OPERATIONS.md, 최신 결과는 상위 review-20261031/에 있으며 completion-20261030/와 이전 hour-draft-20261030/와 supporter-policy-20261030/ 결과도 보존했다.
