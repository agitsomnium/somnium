## 재사용과 추가

공개 사이트·일정·영상 운영은 그대로 유지한다. 화면은 실제 `assets/tokens.css`, Pretendard와 검은고딕을 재사용한다. 회원용 서버·회원 DB·인증메일·관리자 권한·비공개 영상/자료 저장소를 별도로 추가한다. 회원 전용 URL을 공개 목록이나 YouTube 설명·수집 CSV에 넣지 않는다. 후원 확인은 한빛누리에서 사람이 하고 상태만 이 시스템에 기록한다.

노아 기획: Hub log `e09793f2-892e-455a-809c-eb908ac8937e` (2026-10-29). 최신 사용자 요청에 따라 초대 전용이 아닌 신청 → 이메일 확인 → 수동 승인 경로를 구현했다. 운영 홈페이지의 북클럽 참가비에는 후원회원과 아지트솜니움 회원의 혜택도 다르게 표시되어 있으므로 두 유형을 합치지 않는다. 실제 회원의 중복 자격은 운영 데이터 모델에서 별도 entitlement 행으로 관리한다.

## 클라우드 구현 시 확정할 구조 (미적용)

1. 솜니움 전용 Supabase 조직과 프로젝트. 개인 허브 프로젝트에는 회원 행·인증·비공개 영상·후원 장부를 만들지 않는다. 관리자 2명이 각자 계정을 소유하며 기관이 정한 청구/복구 연락처를 등록한다.
2. Supabase Auth의 이메일 OTP와 custom SMTP. 신청 이메일 확인은 대기 회원으로만 처리한다. 로그인 메일 요청은 서버에서 승인 상태를 확인하고, Auth 계정 존재·이메일 확인만으로 강의 권한을 주지 않는다.
3. 신청 프로필(이름·생년월일·전화·이메일·동의 버전/시각), 이용권한(후원회원/아지트솜니움 회원/기존 유료 수강생), 관리자 권한, 강의/자료 메타데이터, 관리자 작업 이력을 분리한다. 후원금액·한빛누리 거래 행은 저장하지 않는다. 신청자가 자기 상태·대상·role을 갱신할 수 없게 한다.
4. 모든 노출 테이블에 RLS. 인증·소유·현재 승인 상태·대상을 함께 검사한다. 관리자 권한은 서버 관리 테이블에서 확인한다. 사용자가 수정 가능한 user_metadata나 오래된 JWT 승인값만으로 판단하지 않는다. 서비스 secret은 서버 전용이며 빌드에 넣지 않는다.
5. 비공개 R2 또는 Supabase Storage. 원본 public URL/외부 YouTube 일부공개 iframe은 회원 보호로 인정하지 않는다. Cloudflare Worker 등 서버가 로그인 세션과 현재 DB 권한을 확인하고 영상 Range/짧은 스트리밍 세그먼트·자료를 전달한다. 중지 후에도 유효한 직접 signed URL을 길게 발급하지 않는다. 이미 받은 버퍼/다운로드 회수는 불가능하다.
6. 테스트용 별도 서비스 URL은 Cloudflare Access의 관리자 이메일 허용목록으로 제한한다. 우선 가상 데이터만 연결하고 운영 도메인은 변경하지 않는다. 클라우드용 API는 현재 로컬 `server.py`와 시험 메일함을 그대로 배포하지 않고 별도 어댑터로 구현/시험한다.
7. 관리자용 강의 업로드는 private 저장소에만 연결. 업로드 자료의 허용 형식·용량·권한·게시 범위를 검증하고 감사 이력을 남긴다. 현재 시험은 MP4/텍스트만 지원하며 실제 문서 업로드나 장시간 영상 변환은 별도 작업이다.
8. 기관 소유 CI에서 백업 예약: DB와 객체 원본/메타데이터를 별도 백업하고 복구 담당·주기·보관기간을 정한다. Supabase DB 백업만으로 Storage 객체 파일이 복구된다고 가정하지 않는다. 운영 클라우드의 백업/복원은 아직 구축하지 않았다.

## 필요한 설정과 예상 비용

아래는 후보 구성의 계획값이며 결제·계정 생성·실제 메일 발송은 하지 않았다. 2026-10-29 공식 가격표 조회 기준, 세금·환율·추가 사용량 별도.

| 대상 | 필요한 설정 | 비용 기준 |
|---|---|---|
| Supabase | 전용 조직·프로젝트 소유 관리자/지역/청구 | Free 시험 가능(저활동 1주 후 정지 가능), Pro 첫 프로젝트 월 $25부터 |
| API 서버 | 기관 Cloudflare의 Worker·접근 제한·서버 secrets | Workers Paid 월 $5 최소 + 사용량. Free 시험 한도 검토 가능 |
| 비공개 영상 | R2 private 버킷·직접 공개 접근 끄기·권한 확인 전달 | Standard 월 $0.015/GB, 무료 10GB 적용 및 요청 비용 별도. 트랜스코딩 별도 |
| 인증메일 | 기관 발신 주소·발신 도메인 DNS(SPF/DKIM 등)·SMTP 공급자 | 공급자/월 인증 건수 확정 뒤 산정. Supabase 기본 SMTP는 팀 주소 외 발송 제한 |
| 백업 | 기관 소유 저장소·CI 권한·복구 담당 | 용량/보관기간/추가 사본에 따라 산정 |

예: Supabase Pro + Workers Paid의 기본 합계는 월 $30 + 메일/저장/백업/초과량이다. R2 100GB 한 사본의 저장료만 단순 계산하면 무료10GB 차감 후 약 $1.35/월이며 영상 서비스 총비용은 아니다. 공급자·실용량 확인 후 선택한다.

출처: [Supabase 가격](https://supabase.com/pricing), [SMTP 제한](https://supabase.com/docs/guides/auth/auth-smtp), [Workers 가격](https://developers.cloudflare.com/workers/platform/pricing/), [R2 가격](https://developers.cloudflare.com/r2/pricing/).

필요한 사람 결정: 소유 관리자 이메일 2개, 발신 주소/도메인, 기관 계정 소유·비용 담당, 테스트 허용자, 회원 정책/정보 보유·삭제 기간, 기존 수강생 권리, 강사 허락, 후원 종료 시 처리 기준. 비밀번호·복구 코드를 채팅이나 공개 코드에 쓰지 않는다.

## 확보한 복구 자료

작업 상위 폴더 `~/bin/work/somnium-classroom-20261029/`:

- `production-baseline.bundle`: 현재 운영 코드 전체 Git 이력. git bundle verify 통과.
- `deployed-pages.zip`: 실제 성공한 Pages artifact (`artifact.tar`, 262개 항목).
- `pages-settings.json`, `baseline-manifest.json`: Pages 설정·변수·실제 빌드 경로·기준 SHA와 백업 SHA256.
- `trial-backup/`, `trial-restored/`: 시험 DB·영상·자료를 새 폴더에 복사하고 복원 검증. 인증번호/세션 제외. 실제 운영 백업이 아님.
- `continuity-input.json`, `continuity-finish.json`: Hub 작업 연속상태 참조. Drive 동기화는 하지 않음.

운영은 변경하지 않았으므로 지금 되돌릴 작업은 없다. 코드 복구가 필요한 경우 bundle을 **새 디렉터리에** clone해 기준 SHA를 확인한 뒤 검토한다. 실제 운영 재배포/설정 복원은 별도 승인 후 진행한다. 기존 main에 force-push하거나 새 테스트 브랜치에 운영 배포를 붙이지 않는다.

시험 복원: `python3 classroom/backup_trial.py ../trial-backup ../새-복원폴더` 후 `server.py --state ../새-복원폴더 --port 8766`. 기존 경로는 덮어쓰지 않으며 가상 계정은 다시 인증해야 한다. 맥을 끄면 이 로컬 시험 서버도 멈춘다. 맥 없이 작동하는 요구사항은 다음 클라우드 단계의 통과 조건이다.
